# SDA Academy — Data Analyst

Bienvenue dans le repository officiel de la formation **Data Analyst — Data Analytics, Reporting & Business Intelligence** de SDA Academy.

## 🎯 Objectif de la formation

Cette formation a pour objectif de former des profils capables de transformer des données brutes en informations utiles à la prise de décision.

Notre démarche :

**Question métier → Données → Nettoyage → Analyse → KPI → Visualisation → Insight → Recommandation → Décision**

## 🗓️ Organisation

- **Durée :** 12 semaines
- **Rythme :** 3 séances par semaine
- **Total :** 36 séances
- **Approche :** 70 % pratique / 30 % théorie
- **Orientation :** Data Analysis, Reporting et Business Intelligence

> **État du repository :** la version actuelle contient la documentation et les ressources complètes de la **Semaine 1**. Les autres semaines seront ajoutées progressivement.

## 🔄 Workflow Git

Avant de commencer une séance :

```bash
git pull
```

Après avoir effectué un travail :

```bash
git status
git add .
git commit -m "Description du travail"
git push
```

## 📌 Règles

1. Toujours faire `git pull` avant de commencer.
2. Vérifier son travail avec `git status`.
3. Utiliser des messages de commit explicites.
4. Ne jamais supprimer une ressource commune sans autorisation.
5. Ne jamais publier de mot de passe ou de clé API.
6. Organiser correctement ses fichiers.
7. Les travaux doivent être suffisamment propres pour pouvoir être intégrés à un portfolio.
