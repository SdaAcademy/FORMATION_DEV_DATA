# Travaux des apprenants

Ce dossier contient les productions individuelles ou de groupe réalisées pendant la Semaine 1.

## Structure recommandée

```text
TRAVAUX-APPRENANTS/
└── NOM-PRENOM/
    ├── README.md
    ├── exercices/
    ├── tp-git-github/
    └── projet/
```

## Convention de nommage

Utiliser :

```text
NOM-PRENOM
```

Exemple :

```text
NTEME-JOSIAS
```

## Règles

- Ne pas modifier les ressources communes.
- Ne pas déposer de fichiers contenant des mots de passe ou des clés API.
- Garder des noms de fichiers explicites.
- Documenter le travail dans un README.
- Utiliser Git pour versionner les travaux.
