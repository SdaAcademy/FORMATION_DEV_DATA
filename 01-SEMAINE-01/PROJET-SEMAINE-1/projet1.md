# Projet — Semaine 1

## Analyse descriptive de la satisfaction client

### Contexte

Vous êtes Data Analyst Junior chez **SDA Services**.

La direction souhaite obtenir une première lecture de la satisfaction des clients afin d'identifier les points nécessitant une investigation complémentaire.

### Dataset

`../DATASETS/clients_satisfaction.csv`

### Objectif

Transformer les données en constats métier exploitables.

### Livrable

Votre travail doit contenir :

1. une présentation du problème ;
2. une présentation du dataset ;
3. une analyse de la satisfaction ;
4. une analyse des réclamations ;
5. une comparaison par agence ;
6. une comparaison par ancienneté ;
7. au moins 3 insights ;
8. au moins 2 recommandations ;
9. une limite de l'analyse ;
10. une conclusion.

### Formats possibles

Le travail peut être réalisé avec :

- Excel ;
- Python ;
- ou un autre outil validé par le formateur.

Le rendu doit être accompagné d'un README expliquant la démarche.

### Critères

Le formateur évaluera :

- compréhension du problème ;
- qualité des calculs ;
- pertinence des comparaisons ;
- qualité de l'interprétation ;
- qualité des recommandations ;
- organisation du repository ;
- qualité de la présentation.

Projet1 Semaine 1

## Mission

À partir du dataset `clients_satisfaction.csv`, produire une analyse descriptive répondant à la problématique :

> **« Quels éléments de l'expérience client méritent une attention particulière ? »**

## Étapes

### Étape 1 — Comprendre

Identifiez le problème et reformulez-le avec vos propres mots.

### Étape 2 — Explorer

Présentez :

- nombre de lignes ;
- nombre de colonnes ;
- variables ;
- types ;
- valeurs manquantes.

### Étape 3 — Calculer

Calculez au minimum :

- effectif ;
- satisfaction moyenne ;
- médiane ;
- minimum ;
- maximum ;
- pourcentage de réclamations ;
- satisfaction par agence ;
- satisfaction par ancienneté ;
- satisfaction selon la présence d'une réclamation.

### Étape 4 — Interpréter

Produisez au moins 3 constats accompagnés de chiffres.

### Étape 5 — Recommander

Proposez au moins 2 actions ou analyses complémentaires.

Chaque recommandation doit être reliée à un constat.

### Étape 6 — Limiter

Indiquez au moins une limite méthodologique.

### Étape 7 — Présenter

Préparez une restitution courte de 5 à 10 minutes.

## Règles

- Ne pas inventer de résultats.
- Ne pas confondre corrélation et causalité.
- Citer les indicateurs utilisés.
- Nommer clairement les fichiers.
- Garder un repository propre.
- Ne pas modifier le dataset original.
