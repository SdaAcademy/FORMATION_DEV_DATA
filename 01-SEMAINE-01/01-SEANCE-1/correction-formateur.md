# Correction formateur — Séance 1

## Exercice 1

1. 27 ans → donnée.
2. 27 % des clients ont moins de 25 ans → information.
3. 4,2/5 → donnée.
4. Satisfaction moyenne de 4,2/5 → information.
5. Kinshasa → donnée/modalité.
6. Kinshasa représente 62 % des clients → information.

## Exercice 2

1. Taux de conversion :

80 / 500 × 100 = **16 %**

2. Information possible :
   > 16 % des visiteurs ont réalisé un achat.

3. Insight possible :
   > Une majorité des visiteurs ne convertit pas, ce qui justifie une analyse du parcours d'achat.

4. Questions possibles :
   - Le taux varie-t-il selon le produit ?
   - Varie-t-il selon le canal ?
   - Existe-t-il des différences entre nouveaux et anciens clients ?

5. Recommandation possible :
   > Identifier les étapes du parcours où les visiteurs abandonnent avant l'achat et tester des actions d'amélioration.

## Exercice 3

Réponses ouvertes. Les questions doivent être liées à un enjeu métier.

## Exercice 4

Réponses possibles :

Situation A :
- note moyenne ;
- taux de satisfaction ;
- taux de réclamation.

Situation B :
- chiffre d'affaires ;
- nombre de ventes ;
- panier moyen.

Situation C :
- délai moyen de traitement ;
- délai médian ;
- taux de résolution.

## Exercice 5

Hypothèses possibles :

- acquisition de clients à faible valeur ;
- baisse du panier moyen ;
- changement de mix produit ;
- promotions plus importantes.

Analyses possibles :

- évolution du panier moyen ;
- segmentation des clients ;
- évolution du chiffre d'affaires par produit ;
- comparaison par période.

## Exercice 6

Informations complémentaires possibles :

- distribution des notes ;
- taux de satisfaction ;
- satisfaction par segment ;
- évolution dans le temps ;
