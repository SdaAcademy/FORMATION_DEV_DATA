# Séance 1 — De la donnée à la décision

## Durée

3 heures.

## Objectif

Comprendre le métier de Data Analyst et apprendre à transformer une question métier en problème analytique.

---

# 1. Qu'est-ce qu'une donnée ?

Une donnée est une représentation brute d'un fait, d'une mesure, d'une observation ou d'un événement.

Exemples :

- âge = 29 ;
- chiffre d'affaires = 12 500 USD ;
- satisfaction = 4/5 ;
- ville = Kinshasa ;
- date = 2026-09-21.

Une donnée isolée possède souvent peu de valeur décisionnelle.

---

# 2. Donnée, information, insight et décision

### Donnée

Valeur brute observée.

### Information

Donnée organisée et contextualisée.

### Insight

Interprétation utile qui fait apparaître un phénomène, une relation ou une anomalie pertinente.

### Recommandation

Action proposée à partir des constats.

### Décision

Choix effectué par le responsable ou l'organisation.

### Exemple

```text
Donnée :
42 clients ont donné une note de 2/5.

        ↓

Information :
La proportion de clients ayant donné une note faible est élevée.

        ↓

Insight :
Les clients insatisfaits sont particulièrement nombreux dans un segment donné.

        ↓

Recommandation :
Analyser les causes d'insatisfaction de ce segment.

        ↓

Décision :
Mettre en place une action corrective ciblée.
```

---

# 3. Le rôle du Data Analyst

Le Data Analyst travaille à l'interface entre :

- les données ;
- les outils techniques ;
- les besoins métier ;
- la décision.

Ses activités peuvent inclure :

1. comprendre le besoin ;
2. collecter les données ;
3. vérifier leur qualité ;
4. nettoyer les données ;
5. analyser les données ;
6. construire des indicateurs ;
7. créer des visualisations ;
8. interpréter les résultats ;
9. communiquer les conclusions.

---

# 4. Une bonne analyse commence par une question

Une mauvaise approche consiste à commencer directement par :

> « J'ai un fichier CSV, voyons ce qu'il contient. »

Une meilleure approche consiste à demander :

> « Quelle décision cherche-t-on à prendre ? »

Exemples de questions métier :

- Quels clients sont les moins satisfaits ?
- Quel segment présente le plus de réclamations ?
- Quelle agence obtient les meilleures évaluations ?
- La satisfaction varie-t-elle selon l'ancienneté ?
- Les clients ayant subi une réclamation sont-ils moins satisfaits ?

---

# 5. La chaîne de valeur

```text
QUESTION MÉTIER
       ↓
DONNÉES
       ↓
QUALITÉ / NETTOYAGE
       ↓
ANALYSE
       ↓
KPI
       ↓
VISUALISATION
       ↓
INSIGHT
       ↓
RECOMMANDATION
       ↓
DÉCISION
```

Cette chaîne constitue un principe fondamental de la formation.

---

# 6. Exemple métier

Une entreprise constate que son taux de satisfaction diminue.

Le Data Analyst ne doit pas simplement produire un graphique.

Il doit chercher à répondre à des questions :

- Depuis quand la satisfaction diminue-t-elle ?
- Quels clients sont concernés ?
- Quelle agence est concernée ?
- Quels produits sont concernés ?
- Le nombre de réclamations a-t-il augmenté ?
- Existe-t-il une relation entre réclamation et satisfaction ?

---

# 7. Qualité des données

Avant toute analyse, vérifier notamment :

- les valeurs manquantes ;
- les doublons ;
- les valeurs impossibles ;
- les types de données ;
- les modalités incohérentes ;
- les valeurs extrêmes ;
- les erreurs de saisie.

Une analyse techniquement correcte sur des données incorrectes peut conduire à une mauvaise décision.

---

# 8. KPI

KPI signifie **Key Performance Indicator**, ou indicateur clé de performance.

Un KPI permet de suivre un objectif ou une performance.

Exemples :

- chiffre d'affaires ;
- taux de satisfaction ;
- taux de conversion ;
- nombre de clients ;
- taux de réclamation ;
- délai moyen de traitement.

Un bon KPI doit être relié à un objectif métier.

---

# 9. Communication analytique

Un bon Data Analyst ne se contente pas de dire :

> « La moyenne est 3,6. »

Il explique :

> « La note moyenne de satisfaction est de 3,6/5. Elle indique une satisfaction globalement correcte, mais l'analyse des segments permet d'identifier les groupes présentant les niveaux de satisfaction les plus faibles. »

La deuxième formulation apporte davantage de contexte et ouvre la voie à l'action.

---

# 10. Mini-framework d'analyse

Pour chaque résultat important, utiliser :

### CONSTATER
Qu'observe-t-on ?

### COMPARER
Par rapport à quoi ?

### INTERPRÉTER
Que signifie le résultat ?

### RECOMMANDER
Quelle action pourrait être envisagée ?

---

# 11. À retenir

Le Data Analyst ne transforme pas seulement des fichiers en graphiques.

Il transforme :

**des questions métier + des données**

en :

**des éléments utiles à la décision.**
